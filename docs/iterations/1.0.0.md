## Implementation notes
- References (loaded on demand): agents-md.md, changelog.md, distribution.md, dotagents.md.
- `metadata.version` holds the skill version (the Agent Skills spec has no version field).
- `release` workflow verifies changelog version == `metadata.version`, then creates/pushes the `v<x.y.z>` tag and the GitHub Release on push to main; idempotent (skips existing tag/release).
